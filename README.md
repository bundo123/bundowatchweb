# LUXSTOREC — Boutique Privada de Alta Relojería (Quito, Ecuador)

Aplicación web construida en **Next.js (App Router)**, **React**, **Tailwind CSS v4** y **Lucide Icons**, optimizada para SEO local en Ecuador y conversión directa vía WhatsApp.

## 1. Despliegue Gratis en Vercel (en 2 minutos)
1. Sube esta carpeta a un repositorio en **GitHub** (puedes usar GitHub Desktop o arrastrar los archivos en github.com).
2. Entra a [vercel.com](https://vercel.com), inicia sesión con GitHub y haz clic en **Add New -> Project**.
3. Selecciona tu repositorio `luxstorec` y presiona **Deploy**.
4. Tu web quedará publicada gratis con certificado SSL (ej. `https://luxstorec.vercel.app`).

## 2. Salir en Google
1. Entra a [Google Search Console](https://search.google.com/search-console) y registra tu URL de Vercel.
2. En el menú izquierdo entra a **Sitemaps**, escribe `sitemap.xml` y haz clic en **Enviar**.
3. Pega tu URL principal en la barra superior de Search Console y haz clic en **Solicitar indexación**.

## 3. Agregar Fotos Reales
Coloca las fotografías de cada reloj dentro de `public/relojes/` con el nombre exacto de su `id` (ej. `public/relojes/rolex-submariner-126610ln.jpg`). Mientras tanto, la web muestra automáticamente una ilustración vectorial acorde a cada modelo.
